Introdução
Após entendermos os conceitos teóricos da análise espacial, é hora de iniciarmos a parte 
prática utilizando um Sistema de Informação Geográfica (SIG). Nesta e na próxima aula,  
utilizaremos o QGIS, um software de SIG profissional, gratuito e de código aberto, que se 
tornou uma das principais ferramentas para geoprocessamento no mundo, inclusive na área 
da saúde (QGIS DEVELOPMENT TEAM, [s.d.]).
O sucesso de qualquer análise espacial depende fundamentalmente da qualidade e da  
correta preparação dos dados. Dados mal formatados, com erros ou em sistemas de  
coordenadas diferentes, são a principal fonte de problemas em projetos de SIG.
  
Portanto, esta primeira aula prática é dedicada à adequação de bases de dados, um passo 
crucial e muitas vezes subestimado. Para esta aula, nosso objetivo é preparar dois tipos  
de dados para que possam ser unidos e analisados: uma base de dados de saúde (atributos) 
e uma base cartográfica (espacial).

Conhecendo algumas fontes de  
dados espaciais vetoriais
O formato de arquivo vetorial padrão usado no QGIS é o arquivo de forma ESRI chamado 
shapefile. Um shapefile consiste na verdade de um conjunto de vários arquivos. Os três  
seguintes são necessários:
	
	
	
.shp arquivo que contém as formas vetoriais.
	
	
	
.dbf arquivo que contém os atributos no formato dBase.
	
	
	
.shx arquivos index.
Shapefiles também podem incluir um arquivo com a extensão.prj que contém as informações 
de projeção. Embora seja muito útil um arquivo de projeção, não é obrigatório.

Preparando os dados para o QGIS
Base Cartográfica (Espacial)
A base cartográfica, também chamada de shapefile (.shp), contém a geometria das unidades 
de análise (ex: os polígonos dos municípios do Brasil). Malhas municipais, estaduais e de  
setores censitários podem ser baixadas gratuitamente do site do IBGE.
Para a prática dessa aula vamos utilizar o arquivo: BR_Municipios_2024. Este arquivo  
foi construído e disponibilizado pelo IBGE e já está organizado para este exercício.
Mas você pode ter acesso a ele no link: 
https://www.ibge.gov.br/geociencias/downloads-geociencias.html
organização_do_território > malhas-territoriais > malhas_municipais >  
município_2024 > Brasil > BR_Municipios_2024.zip
Normalmente, o Windows baixa o arquivo na pasta de Download. Repasse o arquivo  
baixado para a pasta que você criou “PraticaQGIS”, clique com o botão direito no arquivo  
e vá na opção extrair.
Adicionando os dados no QGIS
 
	
• 	 Inicie o QGIS.
	
• 	 Abra um novo projeto em branco.
	
• 	 Para abrir os arquivos, vá na barra superior e clique em Camada > Adicionar  
	
	
Camada 	> Adicionar Camada Vetorial. Busque o diretório onde o arquivo foi salvo  
	
	
clicando nos três pontos em Fonte> Base de vetores. Configure o formato de dado que 	
	
	
está buscando adicionar, neste caso será ‘shapefile’.
Antes de iniciar a busca de um dado geoespacial é importante definir a escala de 
análise do seu projeto: nacional, estadual ou municipal. Para dados municipais, 
acesse os sites da prefeitura para verificar a disponibilidade de dados ou solicite 
à secretaria de urbanismo.
ATENÇÃO
Crie um diretório na sua máquina chamado “PraticaQGIS” (sem espaço) em um 
caminho que você memorize.

===== PAGE 5 =====
Anteriormente, baixamos a tabela de número de casos de dengue notificados por ano para 
os municípios do BR. Suponhamos que você queira calcular a taxa anual de dengue para 
cada município e para isso precise adicionar a sua tabela a população.
Dados de população são gerados pelo IBGE. Para obter dados da população por município 
de anos não censitários bastar ir em https://sidra.ibge.gov.br, selecionar os anos que deseja 
(no caso da prática selecionamos 2024 e 2025 e municípios como nível territorial).
Passos para Adequação: 
Limpeza da Tabela: Abra o arquivo em um editor de planilhas (Excel, LibreOffice Calc).  
Remova linhas de cabeçalho e rodapé desnecessárias, mesclagens de células e caracteres 
especiais dos nomes das colunas. A primeira linha da tabela deve conter os nomes das  
colunas (variáveis), e as linhas seguintes, os dados. 
Salvar em Formato Adequado: O formato mais compatível para importação no QGIS é o 
CSV (Comma-Separated Values). Ao salvar, escolha a opção "CSV (separado por vírgulas)" 
ou "CSV (UTF-8)". O UTF-8 é recomendado para garantir que caracteres como acentos  
e "ç" sejam preservados (PROGRAMMING HISTORIAN, [s.d.]).
Para acompanhar como tratar o dado por completo e o cálculo da taxa, clique aqui! 
	
• 	 Para adicionar os dados tabulares no QGIS, na barra superior vá em  
	
	
Camada > Adicionar Camada > Adicionar Camada de Texto Delimitado. Clique no  
	
	
arquivo dentro do diretório e Abrir.
	
• 	 Antes de Adicionar o dado, configure a entrada como a delimitação sendo tabulado 
por 'ponto e vírgula’, tipo de dado sem geometria e o código do município no formato 'string’ 
- texto. E os demais campos de casos, população e taxa como numérico.
Adequando a tabela de atributos dos dados
Verificação do Código de Ligação: Para unir a tabela de saúde a um mapa, precisamos  
de um campo chave (ou código de ligação) comum a ambas as bases. Para dados municipais 
no Brasil, o código ideal é o código do município de 6 ou 7 dígitos do IBGE. Verifique se sua 
tabela de saúde possui essa coluna e se os códigos estão formatados como número ou texto, 
sem pontos ou traços.

Criar um novo campo com CD_MUN reduzido para 6 dígitos na tabela de atributos no 
dado espacial BR_Municipios_2024:
	
• 	 Abra a tabela de atributos: Clique com o botão direito na camada g Abrir Tabela  
	
	
de Atributos.
	
• 	 Abra a Calculadora de Campos: Ícone da calculadora g Abrir Calculadora de Campos.
Configure o novo campo:
	
a. 	Marque Criar um novo campo;
	
b. 	Nome do campo: CD_MUN6;
	
c. 	 Tipo: Texto (string);
	
d. 	Comprimento: 6.
Use esta expressão: left("CD_MUN", 6)
	
•	 Clique em OK.
	
•	 Isso pega apenas os 6 primeiros caracteres do código de 7 dígitos.
O novo campo é criado de forma temporária para salvá-lo na tabela de atributos vá na barra 
superior e clique em Salvar alterações        . Depois saia do modo de edição clicando ao lado 
em Alternar modo de edição        . 
	
	
Observe que a coluna do novo campo aparece no final da tabela de atributos.
Unindo as Bases de Dados no QGIS (Join) 
Com as duas bases de dados gráfica (mapa) e não gráfica (tabela) adequadas, o próximo 
passo é realizar a união das duas (Join). Essa operação irá vincular os dados da sua tabela  
de saúde (.csv) aos polígonos do seu mapa (.shp) com base no campo chave comum  
(QGIS DOCUMENTATION, [s.d.]).
Passos para o Join: 
Abrir as Propriedades da Camada Vetorial: Clique com o botão direito na camada do mapa 
(o shapefile) e vá em Propriedades.


===== PAGE 7 =====
	
•	 Acessar a Aba "Uniões" (Joins): No menu à esquerda da janela de propriedades,  
	
	
selecione a aba Uniões. 
	
•	 Criar uma Nova União: Clique no ícone de "+" (ou "Adicionar nova união"). Uma nova  
	
	
janela se abrirá: 
	
• 	 Unir Camada: Selecione a sua tabela .csv. 
	
• 	 Unir Campo: Selecione a coluna com o código do município na sua tabela .csv.  
	
• 	 Campo Alvo: Selecione a coluna com o código do município na tabela de atributos  
	
	
do shapefile. 
	
• 	 Clique em OK. 
Verificar o Resultado: Após confirmar a união, abra novamente a tabela de atributos do  
shapefile. As colunas da sua tabela de saúde agora devem aparecer ao lado das colunas  
originais do mapa. A união é temporária. Para torná-la permanente, você deve salvar a  
camada com um novo nome.
Para salvar um shapefile com um novo nome de forma segura é recomendado exportá-lo  
com um novo nome, dessa maneira todos os arquivos que o compõem também receberam o 
mesmo nome.
	
• 	 Clique com botão direito na camada e vá em Exportar > Guardar elementos como.
	
• 	 Selecione o tipo de dado que deseja salvar ‘shapefile’ e o local onde deseja salvar  
	
	
o shapefile em Nome do arquivo.
	
• 	 Clique Salvar e OK.
Ao final desta aula, você terá um único arquivo shapefile contendo tanto a informação  
espacial (geometria dos municípios) quanto os atributos de saúde que você deseja analisar. 
Esta camada de dados unificada é a matéria-prima para a criação de mapas temáticos, que 
será o foco da nossa próxima aula prática.

Ferramentas básicas de navegação QGIS
Agora que ajustamos a camada, vamos explorar algumas ferramentas de navegação.
	
• 	 Movendo o scroll do mouse você pode dar zoom + ou -. Essas opções também estão  
	
	
disponíveis na barra superior de ferramentas nos ícones:
O ícone Ver tudo permite retornar a visualização total do projeto.
	
• 	 Outra opção é deslocar o mapa de um lado para outro usando o ícone:
	
• 	 Caso esteja testando o melhor zoom de visualização, você pode comparar o antes  
	
	
com o depois usando esses ícones.
	
• 	 Podemos também identificar feições usando o ícone         e clicando no mapa.  
	
	
Vai aparecer um box com os atributos da feição. Observer que a informação do box  
	
	
é referente à camada que está ativa, caso queira mudar clique na camada de  
	
	
interesse antes de selecionar a feição no mapa.
Salvando um projeto
Para finalizar vamos salvar o projeto iniciado, para visualizações futuras. Salvar um projeto 
garante que a visualização editada fique salva para ser vista novamente, mas isso não  
impede que o shapefile seja usado e visualizado em outro projeto ou em outro programa de 
Sistema de Informação Geográfica (SIG) que aceite o shapefile como dados de visualização.
Podemos usar o ícone         ou ir em Projeto > Salvar. O projeto do QGIS tem o formato .qgz,  
vamos salvá-lo como Aula 1 na pasta do curso.
